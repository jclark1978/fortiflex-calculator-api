# Changelog

All notable changes to the FortiFlex BOM Calculator are documented here.
Versions refer to the `webgui/index.html` plugin version unless noted otherwise.

## [0.7.0] - 2026-08-24

### Added
- Row selection (checkboxes) on the BOM table, scoped to a single product family at a time.
- Delete selected rows action.
- Bulk-edit guard: bulk edit is blocked across multiple product families with a toast explaining why.
- Resizable table columns, with saved widths persisted under `fortiflex_bom_col_widths_v1`.

## [0.6.0] - 2026-08-06

- Last version published prior to this changelog's introduction. See commit history for details.

## [0.1.4] - 2026-08-06 (browser-extension)

- Initial public release of the FortiFlex API Connector browser extension.
