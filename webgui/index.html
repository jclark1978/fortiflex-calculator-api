Install the connector
  1. Choose Download connector, then unzip the download.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Choose Load unpacked, select the unzipped browser-extension folder, then refresh this calculator.

Install the companion extension once on each Mac or PC. Its settings page provides Save & test connection and Remove credential actions.
