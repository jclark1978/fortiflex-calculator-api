# FortiFlex API v2 reference

This directory contains the local OpenAPI reference documents used while developing the calculator:

- `configurations.openapi.json`
- `entitlements.openapi.json`
- `groups.openapi.json`
- `programs.openapi.json`
- `tools.openapi.json`

The calculator currently calls `programs/list`, `tools/metadata`, and `tools/calc`. The additional definitions are included as reference material for future FortiFlex work.

These files document the API contract; they do not contain user credentials or locally generated API responses. Fortinet's current published API documentation remains authoritative.
